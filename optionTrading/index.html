Options Trade Analyzer

Model expected value, probability of profit, and risk/reward for single- and multi-leg option trades before you place them.

Not investment advice. This is a personal analysis tool — it places no orders and holds no brokerage connection. No live market data feed is wired up (this is a static site with no backend to safely hold an API key), so every price, volatility, open-interest and earnings-date figure below is either your input or a Black-Scholes model estimate — never a live quote. All probability and expected-value figures are estimates from that model, not guarantees.
