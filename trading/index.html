Owner tools: set up your GitHub token ▾
For the site owner only. Create a fine-grained personal access token scoped to just this repository, with Actions: Read and write permission (nothing else needed — it only triggers a workflow; the workflow itself commits using GitHub's own built-in token, not yours). The token is stored only in this browser's local storage and is sent only to api.github.com — never anywhere else, never committed to the repo. Anyone with access to this unlocked browser could see or use it, so don't paste it on a shared/public computer.
